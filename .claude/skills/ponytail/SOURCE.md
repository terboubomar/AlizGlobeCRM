# Source

The ponytail skills (`ponytail`, `ponytail-review`, `ponytail-audit`,
`ponytail-debt`, `ponytail-gain`, `ponytail-help`) are copied unchanged from
https://github.com/dietrichgebert/ponytail at commit `ebd8654` (version 5.3.3),
under the MIT licence in `LICENSE`.

Only the skill files are included. The upstream plugin's hooks (auto-activation
at session start and on every prompt, the status band, the usage ledger and its
optional webhook) are not installed. Use `/ponytail` to turn the mode on.

To update: copy `skills/<name>/SKILL.md` from a newer upstream commit and
change the commit above.
